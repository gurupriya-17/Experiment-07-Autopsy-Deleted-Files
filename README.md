# Experiment 7: Inspect Deleted Files Using Autopsy

## Aim
To inspect deleted files in a forensic image using Autopsy.

## Tool Used
- Autopsy

## Procedure
1. Open Autopsy and create a new case.
2. Add the required disk image as the data source.
3. Configure and run the available ingest modules.
4. Navigate through the file system results.
5. Locate the deleted files section or deleted-file entries.
6. Inspect the available file names, paths, and metadata.
7. Record the findings and capture screenshots.

**Note:** Use an authorized forensic image and preserve the original evidence. A deleted-file entry does not necessarily mean that its contents can be recovered.
